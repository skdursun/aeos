# Short Bug Title
One to three sentences describing the verified defect, impact, and durable fix or prevention point.

## Context
Where the bug appeared and why this note should be reused.

## Symptoms
- Observable failure or regression.
- Error message, behavior, or condition that identifies it.

## Cause
Concise root cause once verified.

## Fix
What changed or should change to resolve it.

## Use When
Use when similar symptoms, files, commands, or failure modes appear.

## Reuse Guidance
Check the cause before applying the fix, then verify the same behavior no longer occurs.
